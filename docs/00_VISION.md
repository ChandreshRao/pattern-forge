# PatternForge Vision

**Status:** Source of truth for product intent. Prefer this file and the rest of `docs/` for decisions.

## Vision

PatternForge is a story-driven learning platform that teaches learners to recognize problem-solving patterns instead of memorizing coding problems.

It is not a LeetCode clone. Every quest is an algorithmic challenge hidden inside a narrative. The long-term goal is a reusable **Curriculum Engine** that can teach any technical subject through interactive campaigns.

## Mission

Transform technical education from:

**Read theory → Solve → Read solution → Forget**

into:

**Story → Discover → Think → Build → Reflect → Master pattern → Apply again**

Learners should leave thinking: *“I know WHY this solution works.”* — not *“I remember seeing this problem.”*

## Product philosophy

**Prioritize:** pattern recognition, curiosity, discovery, reflection, incremental learning, long-term mastery.

**Avoid:** memorization, copying editorials, AI solving problems, spoiler hints, grinding.

## Educational philosophy

Teach intuition first. Students discover the algorithm naturally.

Never open with “Today’s topic: Sliding Window.” Frame a mystery in the world. After the learner solves, reveal: *You discovered Sliding Window.*

The pattern is revealed **after** discovery.

## Product identity

**Is:** Duolingo-like practice rhythm, Pokémon-style progression, Professor Layton mystery solving, story-first education, pattern-first learning.

**Is not:** another coding challenge site, LeetCode clone, or AI tutor that replaces curriculum.

## Core learning loop

Choose campaign → Enter chapter → Receive story → Investigate mystery → Write code → Judge → Reflection → Pattern revealed → XP → Unlock next quest.

## Core principles

1. Teach patterns, not problems.
2. Story should motivate, never distract.
3. Reflection matters more than acceptance.
4. Educational consistency beats AI novelty.
5. Reuse before building.
6. Keep AI optional.

## Gameplay model

Player explores **campaigns**. Campaigns contain **chapters**. Chapters contain **quests**. Quests teach **patterns**. Patterns increase **mastery**. Mastery unlocks progression.

- **Campaign progress:** story completion, chapter unlocks, quest completion (per campaign).
- **Global knowledge:** XP, rank, achievements, pattern mastery, Codex (later), cosmetics (later).

## Curriculum engine

DSA is the first curriculum. The engine stays the same; only content packs change (SQL, system design, networking, design patterns, OS, ML, security, cloud, and more later).

Story/theme presentation stays independent of educational canon.

## Long-term vision

PatternForge should become the most engaging technical learning platform where learners build intuition through exploration, reflection, and mastery — supporting multiple curricula, optional AI mentoring, and themed story worlds on one curriculum engine.
